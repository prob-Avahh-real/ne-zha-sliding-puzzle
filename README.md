# Ne Zha Sliding Puzzle

Welcome to the Ne Zha Sliding Puzzle game! This project is a fun and interactive sliding puzzle game featuring characters from the movie "Ne Zha". 

## Project Structure

The project is organized as follows:

```
ne-zha-sliding-puzzle
├── public
│   ├── index.html          # Main HTML file for the game
│   └── assets
│       └── images         # Directory for image assets
├── src
│   ├── main.ts            # Entry point for the TypeScript application
│   ├── game.ts            # Game logic management
│   ├── board.ts           # Sliding puzzle board representation
│   ├── styles.css         # Styles for the game
│   └── types.ts           # Type definitions and interfaces
├── package.json           # npm configuration file
├── tsconfig.json          # TypeScript configuration file
└── vite.config.ts         # Vite configuration file
```

## Getting Started

To get started with the Ne Zha Sliding Puzzle game, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd ne-zha-sliding-puzzle
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the development server**:
   ```
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:3000` to play the game!

## Game Features

- **Interactive Gameplay**: Slide the tiles to arrange them in the correct order.
- **Character Images**: Enjoy beautiful images of characters from the "Ne Zha" movie.
- **Responsive Design**: The game is designed to work on various screen sizes.
